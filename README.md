# M Skin Couture

Editorial website for **M Skin Couture** (mskincouture.com) — Myriam’s signature glow and skin rejuvenation treatments.

Design language follows [Minimal by Hadda](https://minimalbyhadda.com): cream canvas, full-bleed hero photography, hidden menu, text-link CTAs, and asymmetrical editorial image grids.

## Pages

- `/` — Home (hero, quote, treatments promo, signature methods)
- `/treatments.html` — Full treatment menu from Myriam’s brief
- `/about.html` — About Myriam
- `/contact.html` — Bookings enquiry (mailto)

## Local preview

```bash
python3 -m http.server 8080 --bind 127.0.0.1 --directory .
```

Open `http://127.0.0.1:8080`.
